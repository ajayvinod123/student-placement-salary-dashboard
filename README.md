# 🎓 Student Placement Analysis Dashboard

## 📌 Project Overview

The **Student Placement Analysis Dashboard** is an interactive Microsoft Excel dashboard designed to analyze student placement outcomes, salary distribution, academic performance, technical skills, and company types.

The dashboard presents key performance indicators (KPIs) and visual insights to understand placement trends and support data-driven decision-making.

## 🎯 Project Objectives

- Analyze overall student placement performance.
- Calculate the placement rate and average salary.
- Compare placement outcomes across CGPA categories.
- Analyze the relationship between technical skills and placement status.
- Explore salary distribution among placed students.
- Compare placement numbers across different company types.
- Evaluate assessment scores for placed and non-placed students.

## 📊 Dashboard Highlights

The dashboard includes the following KPIs and visualizations:

- **Total Students:** 9,000
- **Placed Students:** 7,702
- **Placement Rate:** 85.6%
- **Average Salary:** 6.47 LPA
- Placement Overview
- Placement by CGPA Category
- Technical Skill vs Placement
- Average Assessment Score
- Salary Distribution
- Placement by Company Type

## 🛠️ Tools & Technologies

## 🔍 Key Insights

- Approximately 85.6% of students in the dataset were placed.
- A total of 7,702 students were placed out of 9,000.
- The average salary of placed students was reported as 6.47 LPA.
- The dashboard compares placement outcomes across CGPA categories and technical skill levels.
- MNCs account for the highest placement count among the company types shown.
- Assessment scores are compared between placed and non-placed students.

*These insights are based on the figures displayed in the dashboard.*
